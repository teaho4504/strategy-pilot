## 4. 실서버 연결 방법 (Mac)

```bash
VITE_US_API_BASE=http://127.0.0.1:8000 npm run dev
```
백엔드 CORS가 이 출처를 허용해야 한다. 조회만 하며 POST 요청은 코드에 없다.

## 5. 남은 일 (인계서 4장 순서 유지)
1. P0-2 세션 갱신 후 시세·체결 감시 토큰 일관성 (Mac 백엔드)
2. P0-4 청산을 진입 precheck에서 분리 (Mac 백엔드)
3. P1 TradingControl 오표시 (Mac 대시보드)
4. 백엔드에 TOP10·시세·판단표·체결내역·잔고·미체결 조회 API 노출 → `client.ts`에 연결해 `/verify`를 실데이터로 전환
5. 위 완료 후 `/verify` 절차로 1주 왕복 실매매 검증 (사용자 수행)
