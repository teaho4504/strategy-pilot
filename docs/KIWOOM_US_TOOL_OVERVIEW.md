# 키움 미국주식 자동매매 도구 구성

## 현재 제공 범위

이 저장소는 로컬 FastAPI 서버와 Vite React 대시보드로 구성한다. 운영 화면은 실계좌 잔고, 시세, 조건검색, 전략 상태와 체결 성과에 필요한 API만 사용한다.

실주문, 정정, 취소, 환전 신청은 현재 기준선에서 실행하지 않는다. `ust20000`, `ust20001`, `ust20002`, `ust20003`, `ust31302`는 코드 안전 경계에서 차단하며 주문 요청 서비스도 네트워크 전송 전에 항상 중단한다.

## 실행 구조

```text
브라우저
  -> Vite React 대시보드 (localhost:8080)
  -> /api 프록시
로컬 서버
  -> FastAPI (127.0.0.1:8000)
  -> 서버 메모리의 Kiwoom 세션
  -> Kiwoom REST / WebSocket 조회 API
```

App Key, Secret Key, 접근 토큰, 계좌번호는 프런트엔드 소스와 브라우저 저장소에 기록하지 않는다. 계좌 라벨은 마스킹하며 토큰은 서버 세션으로만 다룬다.

## 운영 데이터 범위

- 계좌: 예수금, 평가, 보유종목, 미체결, 체결, 실현손익
- 시장: 현재가, 순위, 차트, 조건검색, FE/FT 실시간 시세·호가
- 주문 사전확인: 주문가능수량 조회

전체 TR 명세 카탈로그와 대시보드 TR 탭은 운영 기능이 아니므로 제거했다. 실제 요청 빌더가 사용하는 TR과 주문 차단용 안전 인벤토리만 코드에 유지한다.

## 단계별 확장 원칙

1. 공식 명세와 실제 요청 빌더를 대조한다.
2. 필요한 계좌·시세 기능만 요청 빌더와 응답 매퍼에 추가한다.
3. 테스트 더블은 테스트 코드 안에서만 사용하며 운영 응답을 가짜 값으로 대체하지 않는다.
4. 실계좌 조회는 서버 세션과 비밀정보 보호 경계를 유지한다.
5. 주문 관련 네트워크 송신은 별도 안전 아키텍처가 승인되기 전까지 차단한다.
